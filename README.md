# Night Shift — Neon Dodge

A tiny, responsive arcade game made with plain HTML, CSS, and JavaScript. No install or build step is needed.

When GitHub Pages is enabled for the repository, play online at
[voltakyy.github.io/mobile-dodge-game](https://voltakyy.github.io/mobile-dodge-game/).
The `Deploy GitHub Pages` workflow publishes the site on pushes to `main`.

## Play

Open `index.html` in a modern browser, or serve this folder with any static web server. Press **Start the run**, then:

- Use **A / D** or **← / →** on a keyboard to switch lanes.
- On a phone or tablet, tap the on-screen arrows, tap either side of the game, or swipe left/right.
- Avoid the orange sparks. You have three hull hits.
- Collect the green light orbs for bonus points. Your best distance is saved in this browser.
- After a run ends, choose **Run it back** or press **Enter** to restart.

The game scales to the available screen size and supports touch and keyboard input.
